# Pulse 波形示例

本文档展示了郊狼（Dungeonlab）波形文件的渲染效果。使用 `[pulse title="标题"]Dungeonlab+pulse:...[/pulse]` 语法即可渲染出逐帧动态波形演示。

---

## 语法说明

```txt
[pulse title="自定义标题"]Dungeonlab+pulse:<全局参数>=<段参数>/<段数据>+section+<段参数>/<段数据>+section+...[/pulse]
```

**格式字段：**

| 组成部分 | 格式 | 说明 |
|---------|------|------|
| 文件头 | `Dungeonlab+pulse:` | 固定标识 |
| 全局参数 | `N,N,8` | 脉冲编号、模式标志、通道数 |
| 段参数 | `C,A,S,R,D` | 曲线类型、幅度、步进、重复、方向 |
| 段数据 | `值-标志,值-标志,...` | 采样点序列，值 0-100，标志 1=关键帧 0=插值点 |
| 段分隔 | `+section+` | 段与段之间 |

## 使用说明

- 波形会自动循环播放，播放头从左向右移动，已播放区域以主题色填充
- 粉色圆点标记关键帧（起点/终点/极值点），透明线条为插值中间点
- 虚线竖线标记多段波形的段落边界
- 点击右上角"下载"按钮可下载原始 `.pulse` 文件
- 矩形框、波形颜色会随文档站主题自动切换
