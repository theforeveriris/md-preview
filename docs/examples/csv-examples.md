# CSV / TSV 交互表格示例

`csv` / `tsv` 代码块会渲染为可排序、可搜索、可按列筛选的交互表格，贴数据不用再截图。

## 基础 CSV

```csv
协议,端口,传输层,说明
HTTP,80,TCP,超文本传输协议
HTTPS,443,TCP,TLS 加密的 HTTP
DNS,53,UDP/TCP,域名解析
SSH,22,TCP,安全远程登录
FTP,21,TCP,文件传输
SNMP,161,UDP,网络设备管理
```

- 点击表头排序：升 → 降 → 恢复原始顺序，数值列按数值比较
- 表头漏斗按钮：按该列的唯一值勾选筛选
- 工具栏搜索框：即时过滤任意单元格命中的行
- 右侧按钮：复制 CSV / 下载 CSV（保留原文）

## 带引号转义的 CSV

逗号或换行出现在单元格内时，用双引号包裹（RFC 4180），引号本身写两个：

```csv
姓名,职务,备注
"张三","网络工程师","CCIE,HCIE 双证"
"李四","运维工程师","擅长 ""救火"""
```

## TSV（制表符分隔）

```tsv
命令	模式	作用
show version	用户/特权	查看版本与运行时间
show ip route	特权	查看路由表
display current-configuration	用户/特权	查看当前配置（VRP）
```
