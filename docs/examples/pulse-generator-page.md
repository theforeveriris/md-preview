# 郊狼波形批量生成页（特殊页面）

郊狼波形批量生成页是系统内置的可视化波形生成工具，面向 DG-LAB 郊狼设备的 `.pulse` 波形创作者。以全屏覆盖层形式呈现，支持按类别/具体波形批量生成、参数调优、随机种子、波形叠加混合，并实时预览生成的迷你波形，提供一键复制源码与下载 `.pulse` 文件的能力。

---

## 一、访问方式

四种入口方式任选其一：

| 方式 | 说明 |
|------|------|
| **URL 参数** | 在站点任意 URL 后追加 `?mode=pulsegen`，例如 `https://theforeveriris.github.io/md-preview/?mode=pulsegen` |
| **设置面板** | 右上角悬浮球 → 设置 → 操作 → 「波形生成器」 |
| **JS 调用** | 在控制台或代码中执行 `window.MarkdownPreview.enterPulseGen()` |
| **Pulse 文档页** | 浏览 [Pulse 波形示例](pulse-examples.md) 时点击波形生成相关入口 |

退出方式：
- 左上角「返回文档站」按钮
- 调用 `window.MarkdownPreview.exitPulseGen()`

退出后 URL 上的 `mode=pulsegen` 参数会被自动移除。

## 三、波形类型体系

内置 **9 大类 · 50+ 种波形模板**，覆盖从基础形状到自然模拟、氛围营造等多种场景。

### 1. 脉冲类（6 种）
快速脉冲、慢速脉冲、双脉冲、单脉冲、窄脉冲串、宽脉冲

### 2. 基础波（4 种）
正弦波、三角波、方波、锯齿波

### 3. 自然类（6 种）
海浪、微风、心跳、弹跳、潮汐、涟漪

### 4. 衰减上升（6 种）
指数衰减、指数上升、快速衰减、缓慢衰减、快速上升、缓慢上升

### 5. 噪声类（3 种）
噪声、粗糙噪声、细碎噪声

### 6. 阶梯折线（3 种）
阶梯波、微阶梯、锯齿折线

### 7. 组合类（5 种）
升降波、脉冲衰减、正弦衰减、阶梯正弦、呼吸波

### 8. 特殊形状（7 种）
尖峰、谷底、平顶、双峰、三峰、山丘、悬崖

### 9. 氛围类（5 种）
地震波、雷鸣、滴答、渐强、渐弱

选择模式：
- **全部**：从全部 50+ 模板中随机抽取
- **按类别**：勾选若干类别，仅从被选中的类别中抽取
- **按具体类型**：逐一勾选具体波形名称，精确定位想要的模板

## 四、核心参数详解

### 1. 激烈程度（Intensity）
范围 **1 ~ 10**，每档同时影响以下维度：
| 维度 | 影响说明 |
|------|----------|
| 频率倍率 | 档 1 ≈ 0.3×，档 10 ≈ 4× |
| 振幅比例 | 档 1 ≈ 20% 量程，档 10 ≈ 100% 量程 |
| 关键帧密度 | 档 1 稀疏（≈ 5%），档 10 密集（≈ 45%） |
| 波形尖锐度 | 档 1 平滑，档 10 突变剧烈 |
| 噪声水平 | 档 1 几乎无噪声，档 10 显著扰动 |

### 2. 强度范围
控制波形强度（0~100）的上下界：
- **预设**：低（0~30）、中（10~60）、高（25~85）、最大（40~100）、满量程（0~100）
- **自定义**：分别输入最小/最大强度值

### 3. 小节数
每个 `.pulse` 文件由若干小节（section）组成，每个小节拥有独立的频率范围/模式/时长：
- **固定值**：例如固定 2 小节
- **随机区间**：例如 1~3 小节，每次生成在范围内随机取值

### 4. 数据点数
每个小节内部的脉冲元数据点数量：
- **自动**：根据波形类型与激烈程度自动推导（推荐）
- **固定值**：例如固定 30 点
- **随机区间**：例如 10~40 点

### 5. 插值类型
影响关键帧之间的过渡形态：
- **线性**：等速过渡，最常用
- **缓入**（ease_in）：慢起快停
- **缓出**（ease_out）：快起慢停
- **缓入缓出**（ease_in_out）：平滑 S 型

### 6. 波形叠加混合
开启后，每个波形会叠加两种不同类型的子波形，生成更复杂的组合效果。叠加比例根据随机种子动态分配。

### 7. 随机种子
- 留空：每次生成使用 `Date.now()`，结果完全不同
- 填入任意数字/字符串：相同种子 + 相同参数 = 完全一致的波形结果，便于分享与复现

### 8. 生成数量
一次批量生成的波形数量，范围 **1 ~ 20**，以 3 列网格排布迷你预览。

## 五、预览区操作

生成后每个卡片包含以下功能按钮：

| 按钮 | 说明 |
|------|------|
| 迷你波形 | 实时循环播放的 `[pulsemini]` 预览，直观感受波形节奏 |
| 类别标签 | 显示波形所属大类，悬停可查看具体波形类型名 |
| 复制源码 | 一键复制完整的 `[pulse]...[/pulse]` 标签代码，可直接粘贴到 Markdown 编辑器中 |
| 下载 `.pulse` | 下载官方格式的 `.pulse` 文件，可导入 DG-LAB 郊狼 App 使用 |
| 清空预览 | 顶部工具栏按钮，清空当前所有生成结果 |

## 六、生成的 `.pulse` 文件格式

生成器严格遵循 DG-LAB 官方 3.4.4+ 导出规范：

```
Dungeonlab+pulse:<休息时长>,<速度倍率>,<未知参数>=<小节1>+section+<小节2>+section+...

小节格式:  <频率A>,<频率B>,<时长>,<频率模式>,<开关>/<强度>-<类型>,<强度>-<类型>,...
```

| 参数 | 取值 | 说明 |
|------|------|------|
| 休息时长 | 0-99 | ×0.1 为实际秒数 |
| 速度倍率 | 1 / 2 / 4 | 播放速度 |
| 频率A/B | 0-83 | 脉冲频率滑块值，通过映射表换算为 Hz |
| 时长 | 0-99 | 小节时长滑块值，通过映射表换算为秒 |
| 频率模式 | 1-4 | 1=固定 / 2=节内渐变 / 3=元内渐变 / 4=元间渐变 |
| 开关 | 0/1 | 是否启用该小节 |
| 数据类型 | 0/1 | 0=普通脉冲 / 1=锚点脉冲（可编辑控制点） |

频率与时长映射表参考 [Pulse 波形示例](pulse-examples.md) 中的参数解析。

## 七、与渲染器的搭配使用

生成器产出的结果可与以下渲染能力无缝衔接：

- **完整波形渲染** `[pulse]`：[Pulse 波形示例](pulse-examples.md) 中逐帧演示，支持竖线/曲线、全局/滚动两种视图切换，小节边界以粉色虚线标注，锚点脉冲标记粉色控制点
- **迷你内联波形** `[pulsemini]`：适合在文档中批量展示或嵌入段落，固定竖线 + 滚动模式
- **内置 Markdown 编辑器** `?mode=editor`：将复制的 `[pulse]` 源码粘贴到编辑器 Cell，运行即可实时渲染，配合工具栏「工具渲染 → Pulse 波形」菜单使用
