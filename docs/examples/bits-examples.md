# 位标注块

` ```bits <二进制> `（可空格分组）+ 正文标注行 `位序 | 名称 | 说明`
（位序自最高位起算）：位条可视化、二/十六/十进制速读、点击位定位标注。

## TCP 标志位

**源码**

````markdown
```bits 0100 0010
0 | SYN | 发起连接
6 | ACK | 确认收到
```
````

**渲染效果**

````bits 0100 0010
0 | SYN | 发起连接
6 | ACK | 确认收到
````
（SYN=1、ACK=1 → 第二次握手的 SYN+ACK 报文，二进制值 0x42。）

## 子网掩码 /24

**源码**

````markdown
```bits 1111 1111 1111 1111 1111 1111 0000 0000
0 | 网络位开始
23 | 网络位结束
24 | 主机位开始
```
````

**渲染效果**

````bits 1111 1111 1111 1111 1111 1111 0000 0000
0 | 网络位开始
23 | 网络位结束
24 | 主机位开始
````

## 超长位串（32 位）

**源码**

````markdown
```bits 1111 0000 1010 0101 1100 0011 1001 0110
0 | 起始位 | 最高位
31 | 结束位 | 最低位
```
````

**渲染效果**

````bits 1111 0000 1010 0101 1100 0011 1001 0110
0 | 起始位 | 最高位
31 | 结束位 | 最低位
````

位串过长时，组件头部只保留前后各两组二进制，中间用 `...` 省略；完整位串仍显示在下方位条中。
