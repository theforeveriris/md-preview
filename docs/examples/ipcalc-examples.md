# ipcalc 子网计算块

` ```ipcalc <CIDR> ` 代码块把目标网段渲染为掩码 / 通配符 / 可用范围 / 广播 /
主机数速查卡，并附子网划分表。纯前端计算，零依赖，贴运维常用网段即得结果。

## 单网段

```ipcalc 10.1.1.0/24
```

## 多网段（lang 里一个，正文一行一个）

```ipcalc 192.168.1.0/26
172.16.4.130/28
```

## 主机地址自动归网

写主机地址也行，渲染时自动对齐到所属网络：

```ipcalc 10.20.30.46/22
```
