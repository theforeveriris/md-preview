# 文档图谱与反向链接

文档之间的关系来自**正文里的 markdown 相对链接**：构建期 `iris/scripts/build-links.js`
扫描全部文档，产出 `iris/data/links.json`（谁链接了谁），运行时用它渲染两个地方：

1. **文末反向链接区**——列出「哪些文档链接到了本文」与相关文档；
2. **文档图谱**——把全部文档画成一张可交互的关系网。

## 打开文档图谱

两种入口：

- 命令面板（`Ctrl/⌘ + K`）搜索「图谱」并回车；
- 直接访问 `#/graph`（hash 可分享）。

本文链接了另外两篇文档，所以图谱里会出现对应的边：

访问 [configuration.md](../configuration.md) 就能看到反向链接的实际效果。

## 小结

- 想让两篇文档在图谱里相连：写一条普通的 markdown 相对链接即可；
- 新增文档后需等 `build-links.yml` 构建出新的 `links.json`（push 触发）；
- 无任何链接关系的文档在图谱中默认隐藏（左下角按钮可切换显隐）。
