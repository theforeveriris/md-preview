# 遮罩（剧透）语法示例

使用 `||内容||` 语法可以创建遮罩（剧透）效果，鼠标悬停或点击（移动端）时才会显示内容。遮罩颜色使用当前主题的主题色。

---

## 基础用法

这是一段普通文字，||这是被遮罩隐藏的内容||，后面继续是普通文字。

把鼠标移到上面紫色的色块上，就会显示隐藏的内容。

---

## 行内多个遮罩

今天的考试题答案是：||A||、||B||、||C||、||D||，全选就对了。

---

## 句子中的遮罩

主角最后的结局是||在雪地中独自离去，没有人知道他去了哪里||，留给读者无限的想象空间。

---

## 代码块内的遮罩不生效

行内代码：`||这行代码里的遮罩不会被渲染||`

代码块：

```
||代码块里的遮罩也不会被渲染||
function hello() {
  return ||"world"||;
}
```

## 使用说明

- 使用 `||内容||` 包裹需要隐藏的文字
- **电脑端**：鼠标悬停即可显示内容
- **移动端**：点击遮罩区域显示内容（再次点击其他地方隐藏）
- 遮罩颜色使用当前主题的主题色（紫色）
- 代码块（行内和块级）中的 `||` 不会被解析为遮罩
- 遮罩内容不支持嵌套
- 遮罩内可以放普通文字、数字、符号等行内内容
