# 转换工具示例

悬浮球菜单 → 设置 → **工具与导出 → 工具 → 格式转换工具** 提供三个页签，用于在 HTML、Obsidian 与纯 Markdown 之间转换。

## HTML 导入

粘贴或选择 `.html` 文件，转换为 Markdown：

- 标题、列表、表格、代码块、链接、图片都会保留；
- `script` 等危险标签先净化再转换；
- 转换结果可直接复制或下载。

## Obsidian 导入

粘贴或选择 `.md` 文件，转换为 Markdown：

- `[[wiki]]` 双链保留为普通文本；
- `![[图片]]` 嵌入语法转为图片；
- `> [!note]` callout 转为 Alert 提示框；
- `==高亮==` 保留。

## 导出 Markdown

把当前文档导出为干净的 CommonMark/GFM：

- 去除站点私有注释；
- 规范空行；
- 可复制或下载。

## 入口位置

以上都是界面工具，没有围栏语法。入口在**设置面板 → 工具与导出 → 工具 → 格式转换工具**。
