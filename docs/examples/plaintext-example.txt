纯文本示例（.txt）

这是一个纯文本文件，没有 frontmatter、没有特殊标记。
站点把它当作普通 Markdown 渲染：标题、列表、引用、表格、代码块都能用，
但不会去解析元数据，也不会给它套代码块的样式。

下面是一些普通的 Markdown 写法：

- 列表项一
- 列表项二
  - 嵌套项
- 列表项三

一段引用：

> 纯文本也能当文档读。

一个小表格：

| 字段 | 说明 |
|------|------|
| name | 文件名 |
| size | 字节数 |

一段代码：

```js
const note = '这是一段普通的代码块';
console.log(note);
```

使用说明：

1. 把 .txt 文件放进仓库的 docs/ 目录，它会出现在左侧文件树里；
2. 也可以直接把本地 .txt 文件拖进页面，放进「本地文件」会话里预览；
3. 两者都按同一套 Markdown 规则渲染。
