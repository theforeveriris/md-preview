# 分栏布局使用示例

使用 `::: columns` 语法可以创建多栏布局，将内容并排展示。每一栏用 `::: column 标题` 标记。

---

## 基础两栏布局

::: columns
::: column 左侧内容
这是左栏的内容，可以放任意 Markdown 格式的文本。

支持**加粗**、*斜体*、`代码`等行内格式。

- 列表项 1
- 列表项 2
- 列表项 3
:::
::: column 右侧内容
这是右栏的内容，同样支持完整的 Markdown 语法。

> 可以放引用块

也可以放普通段落，两栏宽度自动平均分配。
:::
:::

## 优缺点对比

::: columns
::: column ✅ 优点
- 代码简洁易读
- 学习成本低
- 适配各种屏幕
- 移动端自动堆叠
- 支持任意 Markdown 内容
- 与现有主题完美融合
:::
::: column ❌ 注意事项
- 不支持嵌套分栏
- 栏数过多在窄屏体验不佳
- 复杂表格建议使用原生表格
- 单栏内容过长时视觉可能不均衡
:::
:::

## 前后对比

::: columns
::: column 修改前
```html
<div class="row">
  <div class="col-6">
    <h3>标题</h3>
    <p>内容...</p>
  </div>
  <div class="col-6">
    <h3>标题</h3>
    <p>内容...</p>
  </div>
</div>
```
需要手写 HTML，复杂且不直观。
:::
::: column 修改后
```markdown
::: columns
::: column 标题
内容...
:::
::: column 标题
内容...
:::
:::
```
使用 Markdown 语法，简洁优雅。
:::
:::

## 使用说明

### 语法结构

```markdown
::: columns
::: column 栏1标题
栏1内容（任意 Markdown）
:::
::: column 栏2标题
栏2内容（任意 Markdown）
:::
:::
```

### 语法说明

- 使用 `::: columns` 开始分栏容器，`:::` 结束
- 每一栏用 `::: column 标题` 标记
- 标题可以省略，省略后不显示标题栏
- 栏内支持完整的 Markdown 语法
- 所有栏宽度自动平均分配
- **移动端**（屏幕宽度小于 768px）自动变为上下堆叠布局

### 适用场景

- 产品特性列表
- 优缺点对比
- 前后对比展示
- 多图并排展示
- 步骤说明
- 资料分类展示
- 多方案横向对比
