# 站点页面与写作工具

本轮新增的三张聚合页与三个写作/分享工具的入口与用法速览。
聚合页都是虚拟路由页（可收藏、返回键正常、URL 可分享）。

## 一、站点页面

### 全站速查（`#/cheatsheet`）

把全站 ```` ```ios ```` / ```` ```vrp ```` / ```` ```bash ```` / ```` ```powershell ````
等代码块按语言聚合成的**命令速查手册**——「我记得站里写过这条命令」从此秒查。
构建脚本 `iris/scripts/build-cheatsheet.js` 在 CI 自动运行（剥掉 `Router#` / `<Huawei>` / `$`
提示符后收录），每条片段带**来源文档 + 行号**，点击直达原文上下文；命令可一键复制、顶部输入框即时过滤。
也可以按分组直达：`#/cheatsheet/cisco`、`#/cheatsheet/huawei`、`#/cheatsheet/shell`。

入口：侧边栏「目录」聚合页、命令面板（Ctrl/⌘+K 搜「全站速查」）、直接输 URL。

### 站点统计（`#/stats`）

文档数 / 总字数 / 标签数 / 目录数总览卡；近一年**更新热力图**（GitHub contributions 风格，
按文档 modified 时间聚合）；标签分布条形；最近更新列表直链文档；
末尾的**生成式封面墙**为最近更新的文档展示程序化封面（见下文「生成式封面」）。
数据全部来自 `file-tree.json`，纯前端计算。

入口：命令面板搜「站点统计」。

### 死链报告（`#/broken-links`）

CI 全量内链校验（`link-check.js`）的**明细报告页**：按文档分组列出失效链接
（行号 / 类型 / 原因），与 `#/orphan` 巡检页互补——orphan 管内容质量，本页管链接健康。
报告由部署流水线自动产出（`link-check.js --report` → `iris/data/link-report.json`）；
本地自查：

```bash
node iris/scripts/link-check.js --report
```

全部内链有效时显示绿色通过卡。

## 二、写作工具

### 编辑器 AI 助手（自带 Key）

设置面板「工具与导出 → Markdown 编辑器」下方配置（OpenAI 兼容接口）：
API Base URL、API Key、模型名。**Key 仅存本机浏览器，不随设置备份导出，也不发往站点作者**——请求只发往你自己填写的 endpoint。

配置后在编辑器**选中文字**，浮动工具条出现六个动作：

| 动作 | 效果 |
|------|------|
| 润色 | 原位替换选区（技术文档口吻，可 Ctrl+Z 撤销） |
| 译英 / 译中 | 原位替换为译文 |
| 解释 | 选区后插入 `>` 引用块（一句话结论 + 分点） |
| Mermaid | 选区后插入 ```` ```mermaid ```` 图代码 |
| AI✦ | 自定义指令（Ctrl+Enter 执行），如「改写成表格」 |

请求带 60s 超时；等待期间若文档被改动会自动放弃结果，不覆盖你的输入。

### 整页长图导出

把当前文档渲染成**一张竖版 PNG**（排版与屏幕一致，含代码高亮 / 表格 / 图片），
适合微信群 / 朋友圈分享整篇短文。图片转 data URL 内嵌（跨域不可读时占位），
主题变量已固化——暗色主题导出的就是暗色长图。

入口：命令面板「整页长图导出」、设置面板「工具与导出 → 导出 → 整页长图」。

### 生成式封面

没有配图的文档按**路径哈希**确定性生成一张主题配色的程序化封面：
四种构图家族（同心圆 / 流线 / 山脊线 / 方点阵）按哈希挑选与推导参数，
同一文档永远同一张图，零外部资源。当前在「站点统计」（`#/stats`）页的封面墙陈列；
`genCover.getCoverElement() / paintCover()` 已暴露，分享卡片等场景可直接复用。

## 三、命令速记

| 入口 | 说明 |
|------|------|
| `Ctrl/⌘ + K` → 「全站速查」 | 打开 cheatsheet 聚合页 |
| `Ctrl/⌘ + K` → 「站点统计」 | 打开 stats 页 |
| `Ctrl/⌘ + K` → 「死链报告」 | 打开 broken-links 页 |
| `Ctrl/⌘ + K` → 「整页长图导出」 | 导出当前文档 PNG |
| 编辑器选中 → AI✦ | 自定义 AI 指令（需先配 Key） |
