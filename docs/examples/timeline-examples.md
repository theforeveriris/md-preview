# Timeline 时间线组件示例

`timeline` 插件把代码块渲染为单列时间线，适合：

- 网络割接 / 变更窗口计划与执行记录
- 故障复盘（事故时间线）
- 项目里程碑与发布计划

## 基础用法

每行一条：`时间 | 事件 | 备注（可选） | 状态（可选）`。

````markdown
```timeline
2026-10-10 22:00 | 变更评审通过 | 方案与回退计划归档 | done
2026-10-18 01:00 | 割接窗口开启 | 接入层堆叠升级 | doing
2026-10-22 01:00 | 核心链路切换 | 双上联改为单臂，注意环路 | risk
2026-10-25 06:00 | 观察期结束 | 回退窗口关闭 | done
```
````

```timeline
2026-10-10 22:00 | 变更评审通过 | 方案与回退计划归档 | done
2026-10-18 01:00 | 割接窗口开启 | 接入层堆叠升级 | doing
2026-10-22 01:00 | 核心链路切换 | 双上联改为单臂，注意环路 | risk
2026-10-25 06:00 | 观察期结束 | 回退窗口关闭 | done
```

> 若时间线区间**涵盖今天**，会自动在对应位置插入一条「今天」标记线（上例的计划期覆盖了当前日期，所以能看到它）。

## 状态色

状态写在最后一个字段，不写则为中性色。

| 状态写法 | 颜色 | 含义 |
|----------|------|------|
| `done` / `完成` / `已完成` | 绿色 | 已完成 |
| `doing` / `进行中` / `进行` | 主题强调色（实心） | 进行中 |
| `risk` / `风险` / `阻塞` / `延期` | 红色 | 风险 / 受阻 |

```timeline
2026-10-01 | 需求确认 | 完成 | 完成
2026-10-02 | 方案设计 | 进行中 | 进行中
2026-10-03 | 硬件到货 | 供应商延期一周 | 风险
```

## 分隔符

分隔符宽容解析，按优先级：

1. `|` 竖线（推荐）
2. 全角 `：`
3. 半角 `:`（自动避开时间里的 `HH:MM` 冒号）

```timeline
2026-10-01 | 冒号也行：全角分隔
2026-10-02：全角分隔 : 备注也支持半角冒号
```

时间字段可省略（此时整行作为事件标题）：

```timeline
无日期的普通事件，适合不关心时间的清单
```

## 注释

以 `#` 开头的行会被跳过，可用于在代码块里写说明：

````markdown
```timeline
# 下面是回退预案
2026-10-22 03:00 | 回退决策点 | 若核心不通则回退 | risk
```
````

## 时间格式

| 写法 | 说明 |
|------|------|
| `2026-10-22` | 完整日期（用于「今天」标记线判定） |
| `2026-10-22 01:00` | 日期 + 时间，时间原样显示 |
| `10-22` | 省略年份，按当年补全 |

> 时间线里的「今天」标记线依赖浏览器本地时区[^tz]。

[^tz]: 时间线只做本地日期比较，不访问任何时间服务；跨时区协作时请把计划时间写成带时区的绝对时间，或统一按同一个时区换算后再写入文档。

## 实现要点

本插件演示了插件系统的最小形态（参见 [iris/plugins/timeline.js](../../iris/plugins/timeline.js)）：

- **省略 `test`**：默认精确匹配 `language === 'timeline'`
- **同步 `render`**：纯 DOM 生成，无网络、无定时器、无资源注册
- 渲染结果全部经 `escapeHtml` 转义，不引入注入面
