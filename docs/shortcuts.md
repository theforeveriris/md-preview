# 快捷键

Markdown Preview 支持一组全局键盘快捷键，覆盖侧边栏、设置、搜索、文档导航与内容区宽度调节。`⌘` 表示 macOS 的 Cmd 键，`Ctrl` 表示 Windows / Linux 的 Ctrl 键。

---

## 一、文档站快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `Ctrl/⌘ + B` | 折叠 / 展开侧边栏 | 对齐 VS Code 的侧边栏键位；折叠后左上角会浮现展开按钮；状态自动记忆 |
| `Ctrl/⌘ + ,` | 打开 / 关闭设置面板 | 对齐通用「设置」键位惯例，面板打开时再按一次即关闭 |
| `Ctrl/⌘ + K` | 打开搜索命令面板 | 对齐 GitHub / Slack 的搜索键位；面板居中弹出，也可点击侧边栏顶部「搜索文档…」触发行唤起；面板已打开时再按重新聚焦输入框 |
| `[` | 上一篇文档 | 按 DFS 顺序跳转文件树中的上一篇，对齐 GitHub 代码评审的翻页键位 |
| `]` | 下一篇文档 | 同上，方向相反 |
| `Ctrl/⌘ + Alt + =` | 内容区加宽 20px | 步进与设置面板滑杆一致（600–1400px）；全宽模式下会先退出全宽再微调 |
| `Ctrl/⌘ + Alt + -` | 内容区收窄 20px | 同上 |
| `Ctrl/⌘ + Alt + 0` | 内容区宽度重置 | 恢复默认 720px |
| `Ctrl/⌘ + Alt + F` | 正文占满可用宽度 | 开关式；开启后正文铺满窗口，忽略滑杆值 |
| `Esc` | 关闭搜索命令面板 | 面板打开时，Esc 优先关闭面板 |
| `Esc` | 关闭设置面板 | 设置面板打开时，Esc 只关闭面板 |
| `Esc` | 展开折叠的侧边栏 | 桌面端侧边栏折叠时，Esc 可展开；移动端为关闭抽屉 |

> 内容区宽度调整时若设置面板正开着，可实时看到滑杆与数值同步变化。

## 二、媒体查看键位

以下键位仅在对应浮层打开时生效，与上面的全局快捷键互不干扰：

| 按键 | 生效场景 | 功能 |
|------|----------|------|
| `←` / `→` | 图片灯箱 | 上一张 / 下一张 |
| `+` / `-` / `0` | 图片灯箱 | 放大 / 缩小 / 重置缩放 |
| `Esc` | 图片灯箱 / PPT 放映 | 关闭 |
| `←` / `→` | PPTX 全屏放映 | 上一页 / 下一页 |
| `Space` / `Shift + Space` | PPTX 全屏放映 | 下一页 / 上一页 |
| `Home` / `End` | PPTX 全屏放映 | 第一页 / 最后一页 |

## 三、内置编辑器快捷键

编辑器模式（`?mode=editor`）有独立的快捷键体系，与文档站快捷键完全隔离：

| 按键 | 功能 |
|------|------|
| `Ctrl/⌘ + Enter` | 运行当前 Cell |
| `Ctrl/⌘ + Shift + Enter` | 运行全部 Cell |
| `Ctrl/⌘ + Shift + N` | 当前 Cell 下方新建 |
| `Ctrl/⌘ + F` / `Ctrl/⌘ + H` | 搜索 / 替换 |
| `Ctrl/⌘ + B` / `Ctrl/⌘ + I` | 粗体 / 斜体 |
| `Ctrl/⌘ + K` | 链接 |
| `Ctrl/⌘ + \` \` | 行内代码 |
| `Tab` / `Shift + Tab` | 缩进 / 反缩进 |
| `F3` / `Shift + F3` | 搜索下一个 / 上一个 |
| `Ctrl/⌘ + Alt + T` | 新建编辑器标签 |
| `Ctrl/⌘ + Tab` | 切换编辑器标签 |

完整说明见 [编辑器说明](editor.md)。

## 四、冲突保护规则

全局快捷键在以下情况自动失效，避免抢占输入或误触：

1. **编辑器模式**：`body.editor-mode` 激活时，文档站快捷键全部让位给编辑器键位（如 `Ctrl+B` 在编辑器中是粗体）；
2. **输入状态**：焦点位于 `input` / `textarea` / `select` / `contenteditable` 内时不触发（搜索框、设置面板输入项等）；
3. **设置面板打开**：`Ctrl/⌘ + ,`、宽度调整键与 `Esc` 仍可用（便于边看面板边调），其余键位暂停；
4. **灯箱 / PPTX 放映打开**：`[` `]` 等文档导航键不响应，翻页键交给浮层处理；
5. 加了 `Ctrl/⌘ + Alt` 修饰的宽度键位特意避开了浏览器的 `Ctrl + =` / `Ctrl + -` 页面缩放。
