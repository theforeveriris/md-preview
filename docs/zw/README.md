# 排版测试目录

本目录用于验证中文排版校验流水线。

## 文件列表

| 文件 | 说明 |
|------|------|
| `1.0-排版问题样例一.md` | 空格、标点、数字、全半角、行首禁则、重复标点、直引号 |
| `2.0-排版问题样例二.md` | 单位、版本号、冒号问号、配置片段 |
| `3.0-排版问题样例三.md` | 表格、列表、引用、代码围栏、HTML、链接 |

## 预期行为

流水线触发后，机器人会自动修正可安全修复的排版问题，并以
`style: 中文排版自动修正 [skip ci]` 提交。

无法安全自动修复的（如中文旁的直引号）只报告，不改写。
